## Skill

**Multiplayerization** is an original skill by Somphol Boonjing, distilled from the Leab-Tui 3D 1.6.0
multiplayer build and generalized for non-game apps. The workflow, checklists, protocol guidance,
security model and pitfall notes are original work released under the MIT terms of the reference
project.

## Reference implementation

The worked example is **Leab-Tui 3D**:

- <https://github.com/somphol/leab-tui-3d>
- <https://somphol.github.io/leab-tui-3d/>

It uses vanilla HTML5/CSS3/ES2022, Three.js r160 (MIT), PeerJS 1.5.4 (MIT), public PeerJS signalling,
public STUN, system fonts and procedural textures. No third-party brand marks, photographs, fonts,
audio files or private data are redistributed.
