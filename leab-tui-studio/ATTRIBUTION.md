## Reference implementation

The worked example uses:

- Vanilla HTML5, CSS3, ES2022 JavaScript.
- Three.js r160, MIT, loaded from jsDelivr. No Three.js source is redistributed.
- System fonts only. No font files are redistributed.
- Procedural CanvasTextures for the felt, wood, tile faces and backs.
- The Leab-Tui rules, interpreted from Navee Angsuputiphant, “กฏกติกาการเล่น เลี๊ยบตุ่ย” (2016),
  <http://naveea.blogspot.com/2016/03/blog-post.html>.
- Xiangqi tile names and counts cross-checked against Thai Wikipedia, “หมากรุกจีน”.
