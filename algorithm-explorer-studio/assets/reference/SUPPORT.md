## Bugs and feature requests

Open an issue using the repository templates. Include the pattern id, input, step number, browser/OS
and console output. For visual bugs, a screenshot is worth more than a paragraph.

## Security

Do not file a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## What this project does not support

- LeetCode accounts, submissions or judging.
- Code execution in the browser.
- Cloud sync of practice progress.
- Paid curriculum content or problem statements.
- A custom domain or hosted instance other than the GitHub Pages copy.

## Response expectations

This is a personal educational project maintained on a best-effort basis. Clear, reproducible issues
are prioritized; drive-by feature requests may be closed with a pointer to the roadmap.
