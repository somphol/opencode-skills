# Changelog

All notable changes to Algorithm Explorer. The format follows Keep a Changelog; versions follow
Semantic Versioning.

## [1.0.0] — 2026-11-05

### Added

- Fifteen-pattern curriculum: Two Pointers, Sliding Window, Fast & Slow, Merge Intervals, Monotonic
  Stack, Top K, Binary Search on Answer, Tree DFS, Tree BFS, Graph Traversal, Backtracking, Dynamic
  Programming, Cyclic Sort, Reverse Linked List, Union-Find.
- Fifteen pure, deterministic step engines with bounded custom-input parsers and an 18-check
  self-test.
- Fifteen procedural Three.js scenes with orbit controls, per-pattern camera homes, cached canvas
  labels, tweened transitions and a graceful no-WebGL fallback.
- Forty-five reference listings (Python / JavaScript / C++) with semantic mark synchronization.
- Sixty-one canonical LeetCode problems with difficulty filters, search and local checkboxes.
- Thirty pattern-recognition quiz scenarios with immediate explanations and a local personal best.
- Three-tab responsive UI, keyboard shortcuts, help/about dialogs, reduced-motion support.
- 27 Node engine tests, 20 static contract tests, 35 headless-browser checks and 24 in-page checks.
- Release documentation: architecture, reproduction book, curriculum, design, testing, deployment,
  decisions, accessibility, performance, privacy, FAQ and roadmap.
- GitHub Pages deployment, sitemap, robots, favicon, screenshots, social card and build state.
