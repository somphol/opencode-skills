About Algorithm Explorer

Algorithm Explorer is a static, browser-only study studio for the 15 recurring structures behind most software-engineering interview questions. It is inspired by three industry curricula: Grokking the Coding Interview (Design Gurus), the NeetCode 150 roadmap, and the Blind 75.

Every pattern has a deterministic step engine, a distinct 3D scene, synchronized implementations in Python, JavaScript and C++, canonical LeetCode links, and a recognition quiz. No backend, no account, no analytics.

Release 1.0.0 · MIT · Built by Somphol Boonjing with OpenCode + DeepSeek V4.1 Flash. Three.js is pinned to r128 and loaded from a CDN. The visualizations are teaching models, not proofs of correctness.
