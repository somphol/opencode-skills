# Code of conduct

## Our commitment

We want this repository to be a calm, useful place for designers, engineers and agents to study a
procedural interface. Everyone is welcome regardless of experience, identity, background or the
tools they use.

## Expected behaviour

- Be precise and generous in review; critique the work, not the person.
- Assume good faith, especially across language and timezone differences.
- Respect the offline, no-asset and no-network constraints; they are part of the design.
- Credit prior work and the model/tooling that produced it.
- Do not present the fictional maison as a real business or the fictional watch as a real product.

## Unacceptable behaviour

- Harassment, threats, discriminatory language or personal attacks.
- Publishing private information, credentials, session data or machine-specific paths.
- Sexualised imagery or attention; this is a horology and interface study.
- Deliberate disruption, spam or bad-faith re-licensing of third-party work.
- Using the issue tracker to sell real watches, services or unrelated products.

## Scope

This code applies to issues, pull requests, discussions and any space associated with the project.

## Reporting

Open a GitHub issue if the matter can be discussed publicly. For anything sensitive, use GitHub's
private vulnerability reporting on the repository (Security → Report a vulnerability) and mark it
for the maintainer only. Reports are reviewed in good faith; retaliation is not tolerated.

## Enforcement

Maintainers may edit or remove contributions, lock threads, or block accounts that violate this
code. The response scales with severity and repetition, from a private note to a permanent ban.
