# Roadmap

This is a single-maintainer teaching project. The list below is a direction, not
a promise; priorities follow learner value and accessibility.

## Shipped

- [x] Unit 4 companion: inverse functions and restricted domains, Pythagorean
      identity simplification with area models, and a multi-solution equation
      solver.
- [x] Full English ⇄ Thai interface.
- [x] Local progress, badges and JSON export.
- [x] Static CI checks, issue/PR templates and release documentation (1.0.1).

## Next candidates

- [ ] **Keyboard-operable branch point.** Move the active point with arrow keys
      and announce the resulting inverse input.
- [ ] **Free-form proof editor.** Let learners choose from a larger identity
      library and chain substitutions without a fixed expression list.
- [ ] **Interval selector.** Solve equations on `[0, 2π)`, `[0, 4π)` or all real
      numbers with a general-solution format.
- [ ] **More equation families.** Reciprocal equations, equations with phase
      shifts and identities requiring double-angle substitutions.
- [ ] **Printable reference sheet.** A clean black-on-white identity and
      principal-domain table.
- [ ] **Additional locales.** Keep the Thai glossary stable and extract strings
      only if a third language is genuinely maintained.

## Explicit non-goals

- Accounts, cloud sync, leaderboards or classroom dashboards.
- Server-side grading or analytics.
- Framework migration for its own sake.
- Advertising, tracking or third-party embeds.

## How to influence it

Open a feature request using the template and describe the learner problem, not
only the UI you want. Accessibility fixes and translation corrections are
usually fast-tracked.
